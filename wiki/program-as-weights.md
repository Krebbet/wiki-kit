# Program-as-Weights (PAW)

PAW is a programming paradigm for "fuzzy functions" — tasks like log filtering, JSON repair, or intent classification that resist symbolic rule encoding but don't need a large API call on every input. A developer writes a natural-language specification; a 4B neural compiler emits a per-function LoRA adapter; a frozen 0.6B interpreter executes it locally. The compiled artifact is a ~23 MB versioned file that can be cached, version-controlled, and called offline via a two-line Python API. A Qwen3-0.6B interpreter executing PAW programs achieves 73.78% exact match on FuzzyBench, beating Qwen3-32B prompting (68.70%) at ~50× less inference memory, and runs at 31.6 tok/s on a MacBook M3 under Q5_K_M + Q4_0 quantization.

## Method

**Compiler–interpreter abstraction.** Three components: (1) a *pseudo compiler* (off-the-shelf Qwen3-4B, never trained) that rewrites the spec into a clean pseudo-program (task description + I/O examples); (2) a *LoRA compiler* (Qwen3-4B, trained on FuzzyBench-10M) that reads spec + pseudo-program and emits a per-function LoRA in a single forward pass; (3) a *frozen interpreter* (Qwen3-0.6B) that hot-attaches the LoRA and prepends the pseudo-program to user input at inference.

**LoRA generation.** The LoRA compiler extracts prefix-position hidden states from 64 learned prefix tokens, mean-pools them, passes through a shallow MLP, and projects into mixing coefficients over N=64 shared basis matrices per module type (rank r=64, applied to all Q/K/V/O/gate/up/down projections, ~38.5M injected params per function). Simpler aggregation (mean-pool + shared bases) outperforms more expressive per-position and per-layer variants — a non-obvious finding reported without a theoretical explanation.

**Training.** Supervised only: loss is negative mean-token log-likelihood of the target under the frozen interpreter. No RL. The LoRA compiler is trained on **FuzzyBench-10M**, 10M (spec, input, output) triples generated by gpt-5.2, covering 800+ task categories across 29 thematic versions (classification, format repair, NL commands, tool use, agentic tasks, etc.). The dataset is released with the paper.

**Hybrid program format.** Each compiled program is a pair: a discrete pseudo-program (human-inspectable) + a continuous LoRA (opaque). The pseudo-program denoises noisy specs: under heavy typos, feeding the pseudo-program vs raw spec to the interpreter is worth 4.5 pp. The compiled program is analogous to a binary: versionable, distributable via package managers, callable offline.

**Multimodal extension.** Swapping only the compiler for a vision-language model (Qwen3-VL-4B) while keeping the same 0.6B text interpreter lets PAW handle image-conditioned fuzzy functions. Image conditioning is fully encoded in the emitted LoRA; the interpreter never sees pixels.

## Results

| Method | FuzzyBench | Interpreter size | Memory |
|---|---|---|---|
| Qwen3-32B prompting | 68.70% | 32B | ~60 GB |
| PAW (Qwen3-0.6B) | **73.78%** | 0.6B | ~1.2 GB |
| PAW (GPT-2-124M) | 54.39% | 124M | ~0.4 GB |
| Full fine-tune (0.6B) | 58.40% | 0.6B | ~1.2 GB |
| Fixed LoRA r=128 (0.6B) | 51.59% | 0.6B | ~1.2 GB |

- Quantization: Q6_K base + Q4_0 LoRA (623 MB + 23 MB) indistinguishable from bf16; Q4_K_M (484 MB + 23 MB) loses 1.3 pp.
- Robustness: under heavy combined noise (all axes), degrades only 3.7 pp (0.6692 → 0.6326).
- Tool calling: 10-PAW-function pipeline scores 93% on TOOLCALL-15.
- Multimodal: beats Qwen3-VL-4B-Instruct on three CoSyn diagram tasks (Circuit 0.274 vs 0.196, Chemical 0.414 vs 0.258, Music 0.552 vs 0.470) using the same 0.6B text interpreter.
- Empirical ceiling: gpt-5.2 (data generator) 96.09%, gpt-5-mini 91.87%.

**Limitations.** Compiler–interpreter pairs are coupled: switching the interpreter requires retraining the compiler. Single-step only (multi-step compositional programs not yet validated). Best PEFT is task-dependent: LoRA stronger on text/classification; prefix-tuning stronger on long-form structured output (Im2LaTeX, Im2SMILES) where discrete pseudo-program examples crowd the small context budget. Compiler scaling is non-monotonic (inconclusive; unfrozen 4B beats frozen 32B).
