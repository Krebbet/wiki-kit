# Spiking accelerator on an RFSoC FPGA for mmWave ISAC activity recognition

IMDEA Networks / UC3M implement a 132-neuron fully connected SNN plus a streaming spike encoder in the programmable logic (PL) of a ZCU208 RFSoC, for micro-Doppler human-activity recognition on 802.11ay 60 GHz sensing data (DISC-A dataset). They claim 94.7 % accuracy on unseen subjects, 206 µs per 1.73 s window, and 3.4x / 7.6x less measured PL dynamic energy per decision than same-topology int8 ANNs on the same device. The comparison is unusually like-for-like and rail-measured, but it is dynamic-only over idle, static power dominates the prototype, the ANNs are faster per window, and accuracies are optimistic by about 1.5 points. It is an FPGA prototype, not neuromorphic silicon, and the savings are attributed to accumulate-only arithmetic and small area, not to spike sparsity.

## Platform / workload

**Platform.** AMD Xilinx ZCU208 board, XCZU48DR RFSoC (FPGA fabric plus RF data converters; PL = the programmable-logic fabric), Vivado / Vitis HLS 2023.1. VHDL generated by open-source Spiker+ (v2.0.3, patched for an output-neuron-reset bug, reported upstream) from an snnTorch model. Serial processing: neurons in a layer update in parallel, input spikes are fed serially; two's-complement fixed-point weights and membrane potentials; shift-based leak. Authors chose an FPGA over a neuromorphic chip to avoid a second device and power domain, and say the VHDL could be ported to a baseband ASIC (not done).

**Network.** 59 inputs (Doppler bins) -> 128 first-order LIF hidden (subtractive reset) -> 4 LIF outputs (no reset within a window). One time step per micro-Doppler frame (8.64 ms); window N = 200 frames (1.73 s); label = output neuron with most spikes. Beta = 0.9375 (4-bit shift leak); with 4 fractional bits the leak floors to zero, so SNN-S/SS hidden neurons do not leak.

**Encoder.** Per-frame relative threshold: spike if bin > min + theta(max - min), theta 0.75 or 0.85. The frame maximum always fires, so there is no input-sparsity exploitation and latency is near-constant.

**Training.** Offline BPTT, arctangent surrogate gradient (alpha 2), Adam lr 5e-4, batch 64, 15 epochs, cross-entropy on output spike counts. Quantization-aware training (QAT) uses a differentiable copy of the accelerator arithmetic (not part of Spiker+). See [[snn-training-surrogate-gradients]].

**Task.** DISC-A: 433 sequences, 7 subjects, four classes (walk, run, sit/stand, wave hands). Subjects 1-5 train (balanced to 1341 windows/class by Gaussian-noise replication); subjects 6-7 test (812 windows, 68 % walking).

## Measured numbers

All figures are FPGA-implemented and board-measured unless noted; all designs compared at 187.5 MHz (the ANNs do not close timing at 250 MHz). Variants: SNN-S / M / L are small / medium / large hidden configurations; SNN-SS is 3-bit weights with QAT. Per-variant bit-widths (Table I) are omitted here because the source table is garbled.

**Accuracy** (on-board, on-chip encoder, 812 test windows; optimistic, see below):

| Config | Accuracy | Macro-F1 |
|---|---|---|
| SNN-S | 91.4 % | 82.8 % |
| SNN-M | 94.7 % | 90.7 % |
| SNN-L | 95.2 % | 91.8 % |
| SNN-M, theta 0.85 | 93.2 % | 88.7 % |
| SNN-SS (3-bit, QAT, theta 0.85) | 92.7 % | 88.1 % |
| ANN int8 (binary input) | 93.6 % | 88.2 % |
| ANN16 int8 (16-bit input) | 95.9 % | 92.8 % |
| Float32 SNN reference | 94.6 % | 91.8 % |

Seed spread +/-1.7 points (mean 93.1 % over three seeds). QAT at theta 0.85: SNN-SS 92.7 % vs 87.8 % for the same net quantized post-training (five seeds, bit-exact model).

**Latency** (in-PL cycle counter, cycle-exact, <1 % variation between windows; accelerator plus encoder, per 200-frame window at 187.5 MHz):
- All SNN configs: 38,676 cycles = 206 µs.
- ANN: 16,802 cycles = 89.6 µs. ANN16: 19,616 cycles = 104.6 µs. The ANNs are faster per window.
- Through processor/DMA, software adds 225 µs per window (median of 1000 passes).
- Live-stream view: encoder plus accelerator spend about 354 cycles (2 µs) per 8.64 ms frame. Encoder emits spikes within 161 cycles.

**Resources** (post-implementation, accelerator alone, XCZU48DR):

| | SNN-S / M / L / SS | ANN / ANN16 |
|---|---|---|
| LUTs | 4095 / 4529 / 5184 / 3504 | 34,374 / 30,131 |
| Registers | 1824 / 1940 / 2204 / 1688 | 28,891 / 27,306 |
| BRAM tiles | 6.5 / 11 / 14.5 / 5.5 | 14 / 14 |
| DSP | 0 (all) | 200 / 192 |

Encoder adds 611 LUTs + 965 registers. SNN-M plus encoder = 1.2 % of ZCU208 LUTs. Out-of-context vs complete-design utilization differs by 3 % for SNN-M. 3-bit weights halve weight memory and cut LUTs 23 % vs SNN-M (6-bit).

**Power** (boundary: VCCINT rail only, i.e. the PL supply; INA226 monitor, 1 mA resolution, 1000 readings per point, window replayed back-to-back from on-chip memory). Not board power, not processing-system power. Idle rail with bitstream loaded: 33-50 mW (SNN designs), 54-60 mW (ANNs), stable to 0.4 mW. Authors report only the **increase over idle (dynamic)**: SNN-S 1.6 mW, SNN-M 1.8 mW, SNN-L 2.3 mW, SNN-SS 1.2 mW, ANN 14.4 mW, ANN16 27.5 mW. Encoder adds nothing resolvable. Dynamic power changes <0.5 mW with input activity.

**Energy per inference** (PL dynamic only, board-derived; excludes idle/static, receiver, ADC, STFT, DMA, processor): SNN-M 0.38 µJ, SNN-SS 0.25 µJ, ANN 1.29 µJ, ANN16 2.88 µJ. SNN-M at one inference per 1.73 s is 0.2 µW average dynamic power. Static power (33-50 mW) is orders of magnitude above this; the authors state static power dominates the prototype.

**Other.** Raw channel estimates are 15 Mb/s per beam (180 Mb/s for twelve beams) against about 1 b/s for the label. Theta 0.75 gives 6.4 % active input bins; theta 0.85 removes 35 % of input spikes and 25 % of hidden spikes.

## Baseline and comparison honesty

- **Better than usual.** Baselines are same-topology (Linear(59,128), ReLU, Linear(128,4)) int8-weight / 16-bit-activation ANNs generated with hls4ml, on the same device, same wrapper contract and same measurement method. Energy is measured rail power, not estimated.
- **Implementation style confound (authors' own flag).** hls4ml builds a parallel DSP datapath; Spiker+ builds a serial memory-based one. The logic and energy differences include implementation style, not only spiking. hls4ml does not exploit 1-bit inputs, so the binary ANN uses the same multipliers as ANN16. Authors attribute savings to accumulate-only arithmetic, serial processing and small area, not input sparsity.
- **Dynamic-only boundary.** The 3.4x / 7.6x are ratios of mW-level increments over idle. Static/idle (33-60 mW) is excluded and varies with clock regions and placement. The ANNs are also faster per window (89.6 / 104.6 µs vs 206 µs). The 0.2 µW always-on figure excludes the receiver, ADC, channel estimation and STFT, which the paper does not quantify.
- **Selection on test subjects.** No validation subject. Hardware configs, theta, and the best-of-three-seeds float32 run were chosen on the test subjects; the authors say this makes accuracies optimistic by about 1.5 points. SNN-M vs ANN / ANN16 differ by 9 and 10 windows, inside the +/-1.7-point seed spread: "comparable", not better. The headline 94.7 % is SNN-M.
- **Weak accuracy comparator.** The baseline is a tiny MLP, not a CNN. On subject 7 alone SNN-L reaches 92.1 % accuracy / 91.1 % macro-F1, about 5 points behind a CNN (DISC benchmark, mean per-class F1 96.1 %) and a learned-encoder SNN (95.8 % macro-F1) that has 3.5-30x more parameters.
- (synthesis) The result is a clean small-scale digital datapoint for the boundary-and-baseline dependence already tracked in [[../conflicts/snn-energy-payoff]]: the win is arithmetic and area on a mW-scale increment, not event sparsity, and it disappears into the static floor at system level.

## Maturity

Evidenced: FPGA prototype on an RFSoC dev board, full chain from micro-Doppler frame to label in PL, board-measured. Input is a public dataset (DISC) fed via DMA, not a live 802.11ay receiver; the STFT/log front end is not implemented in-radio. No ASIC, no tape-out, not neuromorphic silicon. Single dataset, 7 subjects, one monostatic link, 4 classes.

## Commercial signal

No companies or products. Funding is public: Horizon Europe SNS JU grants IoT-ZERO (No. 101292662) and MultiX (No. 101192521), plus Comunidad de Madrid DISCO6G-CM. Claimed, not evidenced: use as an always-on wake-up classifier in a Wi-Fi AP, an O-RAN Radio Unit (7.2x split, DU sleeps) or a handset. Claimed, not measured: ASIC leakage scales with area and would favor the small SNN.

## Blockers stated

- Static power of the FPGA fabric dominates on the prototype; always-on cost is set by static power/area and by the unquantified receiver, ADC, channel estimation and STFT.
- Fixed-point leak vanishes at low fractional bits (SNN-S loses 3 points accuracy / 9 points macro-F1 vs float32).
- Spiker+ software emulation differs from hardware by up to several points (no saturation, leak or spike-ordering fidelity); the authors built a bit-exact model.
- Encoder always fires the frame maximum: no input-sparsity savings, near-constant latency. An absolute noise floor is proposed, not built.
- About 5-point accuracy gap to convolutional designs on subject 7; small single-link dataset; no validation split; Spiker+ 2.0.3 VHDL bug needed patching.

## Novelty

Refinement / first-of-kind integration, not a new mechanism. Claimed first hardware measurement of SNN inference for ISAC activity recognition on communication-derived channel data on a transceiver-class RFSoC. Contributions: AXI-stream wrapper with cycle-exact latency and per-window reset around Spiker+ cores; streaming per-frame spike encoder; QAT bringing weights to 3 bits within half a point; same-device ANN reference with measured rail power. Closest priors named by the authors: Cicciarella et al. (software SNN, learned/sparse encoding of channel responses), Yu et al. (ICML 2026; latency on a neuromorphic chip, energy estimated theoretically), NeuroRadar (spiking radar front end), Spiker+ (Carpegna et al.).

## Reproducibility

Built on the public DISC dataset and open-source Spiker+, snnTorch, hls4ml, PYNQ. The source states no release of code, bitstream or trained weights for this work; the bug fix was reported upstream. No independent reproduction. Hyperparameters, seeds and measurement method are given in enough detail for partial replication.
