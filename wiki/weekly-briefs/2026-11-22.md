# Trends in the industry
- **The agent becomes the managed object.** LangChain rebuilt LangSmith around a registered agent record (named owner, immutable ID, type, OTLP ingestion of third-party agents), Microsoft's Agent 365 does the same with Entra identities, and MCP's roadmap prioritizes agent identity. Governance is converging on "agents are identities with owners"; the identity-provider integration is still roadmap-only. *(synthesis)*
- **Enterprise multi-agent is settling on orchestrator + declared routing.** Salesforce's Agentforce Multi-Agent Orchestration (GA) pairs an LLM front-door router with Agent Script for deterministic paths and turn-level tracing; IBM and Camunda ship similar planes. No vendor publishes routing-accuracy numbers.
- **Harness evolution is joining weight training.** Microsoft Research's Self-HPO alternates harness search with GRPO and reports the gains are super-additive (+8.5 vs 3.5 and 3.4 alone), with code and models released; a harness-only skeptic paper (2605.30621) is the counterweight. The evolved harness mostly adds submission-hygiene guards.
- **Memory work is moving to lifecycle management.** MEMOIR (reported, unverified) gates consolidation on evidence preservation and re-ranks by post-use attribution; a November preprint finds no dominant memory architecture across 12 systems. Baselines remain weak (cosine) and raw-RAG comparisons absent. *(synthesis)*
- **Benchmarks: easy ones saturate, new ones spread models.** OSWorld-Verified tops ~86% (aggregator-reported) while OSWorld 2.0 best is ~20%; SWE-bench Pro boards now fix the harness.
