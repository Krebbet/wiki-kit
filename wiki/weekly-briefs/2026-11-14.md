# Trends in the industry

- **Weights as an editable surface, no gradient descent.** [[weight-space-programming]] (ingested; MIT CSAIL blog — GPT-6 Astra edits 0.016% of Qwen3.5-0.8B's weights, MATH-500 7.9%→48.1%; vendor-dependent, contested), [[deletion-tuning]] (ingested; learned mask zeroing <0.05% of weights matches full fine-tuning) and Tree-Ising (bit-level repair) all treat weights as directly programmable. (synthesis)
- **Multi-teacher on-policy distillation is now a sustained cluster.** [[p2-mopd]] (ingested; learnable expert task-vector coefficients, 94.7% vs 80.9% recovery) and Reframe follow [[waypoint-opd]], [[ride-opd-residual-extrapolation]] and [[dopd-dual-on-policy-distillation]].
- **"Decision models" / System One become a product category.** Gemini Decision 1, Jev 1.14 and others ship single-pass scorers; [[so-arena]] (ingested) benchmarks 21 of them and separates capability from reliability; extends [[jev-as-a-judge]].
- **Recursive self-improvement is moving down the stack to infrastructure.** InfraRSI, Infrathon, Evolving Infra apply agent self-improvement to training/serving systems, not just harnesses (builds on [[coevo-rsi]]).
- **Agent memory gets a reliability critique.** [[evidence-linked-memory]] (ingested): memory can *regress* performance; evidence-linked lessons cut regression 9.7%→4.5%, while existing memory methods barely beat no-memory.
- **Big MoE / world-model drops continue (AINews, vendor-reported):** Inkling 2 Small (594B/17B-active, open weights reported but conflicting), ERNIE 5.5 Flash Preview (280B/14B), Praxis-1 (Runway world-action model, Apache 2.0).
