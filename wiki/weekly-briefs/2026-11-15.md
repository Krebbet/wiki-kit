# Trends in the industry
- **Agent memory is shifting from "what to store" to "how to inject it".** Forge Decision Context reports compiled imperative rules beating raw retrieved text (95% vs 55% compliance), while a companion NeurIPS paper finds correction memory gives no reproducible gain for pairwise judges. Together with Anthropic's Managed Agents "dreaming" (scheduled memory curation), use-time format is becoming its own axis next to the verbatim-vs-extracted debate. *(synthesis)*
- **Coding-agent vendors are moving from code to shipped apps.** Cursor's Build Live Apps (Nov 5) has cloud agents provision Postgres, SSO auth and hosting behind a publish-time security gate, with Voice Chat the next day; the open question is gate efficacy and app sprawl, neither quantified.
- **Open-source and Chinese-lab harnesses keep arriving as prototypes.** DeepSeek's Harness team shipped a proactive group-chat coding agent (~Oct 31) after Harness v0.1 in August; OpenAI open-sourced its Codex engine in August. Evidence so far is press-only, with no benchmarks or confirmed licence.
- **Ambient, unprompted agents widen the injection surface.** Agents that read group chats or ingest PR/issue content act on untrusted text; the Black Hat 2026 coding-agent RCE findings (hidden harness trust assumptions) are the same class of risk.
- **Multi-agent research is turning to human-team theory and explicit topology configuration** (Teamknitt: 14 deterministic topologies, human-led intervention), but with no results reported yet.
- **Quiet week on primary vendor posts:** no November-dated posts surfaced on the Anthropic or LangChain blogs, and the MCP spec is unchanged since 2026-07-28.
