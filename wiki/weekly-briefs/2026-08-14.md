# Trends in the industry

- **The mastered-prompts / zero-advantage conflict keeps drawing new, structurally distinct attack angles — 3PO is the fourth this quarter.** [[research/rl-optimizers/3po-parameter-exploration]] (arXiv:2608.09805) attacks [[conflicts/mcpo-vs-dapo-mastered-prompts]] from a new direction: instead of discarding (DAPO), regularizing (MCPO), or sidestepping (Cue-GRPO, 2026-08-07), it *prevents* zero-advantage groups from forming by sampling each group's rollouts from multiple IVON-perturbed policies rather than one fixed policy. Four independent papers, four different mechanisms, same open failure mode — the field hasn't converged on a fix, it's mapping the fix-space. Directly informs which normalization/anchoring choice this wiki's own method should make. *(synthesis)*
- **Reference-solutions-as-reward-scaffold is solidifying into a recognizable pattern, not a one-off trick.** [[research/process-reward-models/exprl-mid-training]] (arXiv:2606.17024) hides reference solutions from the policy and uses them only to build LLM-judge grading rubrics for dense reward — joining VPS, IOP, GRPO-VPS, and RREDCoT (all already on the watchlist/wiki) as instances of "use the reference structurally, never as an imitation target." The Setlur co-authorship link to [[research/process-reward-models/pav-rewarding-progress]] makes this a traceable *lineage*, not just a convergent-evolution coincidence — same author, same "process advantage" concept, prover-policy vs. judge-rubric mechanisms two years apart.
- **New mechanistic accounts of in-context learning keep surfacing at roughly one per month, each formally distinct.** [[research/in-context-learning-theory/bdh-cq-recurrent-latent-reasoning]] (arXiv:2608.09888) is the second wholly new ICL-mechanism proposal since [[research/in-context-learning-theory/icl-implicit-weight-update]] (2026-07-03) — an explicit recurrent memory state, architecturally decoupled from a separate latent-reasoning loop, rather than a single implicit weight-update or posterior update. Directly sharpens this wiki's central question ("what does a single example teach a model?") with a fourth candidate answer, and its ARC-AGI-1 cost-efficiency result (new SOTA, independently audited) is a strong empirical anchor most of the other ICL-theory papers lack.
- **Weight-space exploration for RLVR is emerging as a distinct axis from the well-trodden action-space (temperature/entropy) literature.** 3PO explicitly frames temperature scaling as rank-preserving (can only reweight, never reorder tokens) and proposes sampling policy *weights* instead — and cites a concurrent independent paper (arXiv:2602.02555, "Learning to Explore with Parameter-Space Noise") doing the same thing via a different mechanism. Two groups converging on the same idea in the same window is a real signal, not a single group's idiosyncrasy — worth tracking as its own sub-direction next quarter. *(synthesis)*
