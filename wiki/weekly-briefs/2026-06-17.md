# Trends in the industry

- **Data platforms converging on "governed SQL as agent ground truth"** — Databricks' Genie Ontology (live enterprise knowledge graph, continuously updated from Databricks + 50+ connected apps) and the Salesforce+Databricks federated search represent both major data platforms agreeing that enterprise agents need governed SQL data — not document embeddings — as their context layer. Genie's framing: "confident wrong answers are worse than no answer." This displaces RAG-over-documents as the enterprise agent architecture.

- **Managed agent infrastructure becoming hyperscaler table-stakes** — AWS AgentCore adds managed web search (native MCP connector via Gateway) and Bedrock Managed Knowledge Bases GA (June 2026), completing the stack alongside Microsoft Foundry IQ + Toolboxes and Google Managed Agents API. All three hyperscalers now offer framework-agnostic, enterprise-security-compliant managed agent hosting. The DIY-vs-managed trade-off is now a real architectural choice.

- **Flat-rate subscription collapse accelerating — but politically contested** — Anthropic announced (May 13) and then paused (June 15, same day) the Agent SDK credit split. The structural logic is correct; the execution failed under OpenAI price-war pressure, IPO optics, and developer anger. Simultaneously: Microsoft canceling Claude Code licenses enterprise-wide (HN ~350+), GitHub Copilot moving to token billing (June 1). The industry is structurally moving to consumption pricing; the transition is turbulent.

- **Physical AI emerges as a distinct venture category** — Prometheus (Bezos + Bajaj, former Verily) has raised $18.2B total at a $41B valuation to build "artificial general engineer" software for physical systems design (jet engines, chip layouts, drug compounds). Explicitly not robotics — design software. Q1 2026 alone saw $6.4B raised across 27 physical AI companies (vs. software AI agents). Capital is bifurcating.

- **YC P26: agent governance and supply-chain tooling overtake agent applications** — The 194-company Spring 2026 batch is 61% B2B with a 55-company agent infrastructure group. The dominant theme is governing agents already deployed (access control, observability, permissions, identity) rather than building new agent applications. Founders naming incumbents to replace rather than complement — replacement framing has matured from thesis to batch-level pattern.

- **OpenSharing Protocol — Databricks moves to become AI-asset interchange layer** — Donated to the Linux Foundation, backed by OpenAI, SAP, Stripe, and Atlassian, OpenSharing extends Delta Sharing to cover agent skills, model weights, and unstructured data. This is a protocol-level move, not a product launch; Databricks is bidding to be the inter-platform AI-asset exchange standard before any hyperscaler locks it down.
